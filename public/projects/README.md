# Project Images

Drop your project screenshots here, then wire them up in
`src/components/ProjectCards.jsx` by filling each card's `image` field:

```js
image: '/projects/crowdfunding.png',
```

Empty string (`''`) = gradient fallback is shown instead.

## Suggested filenames

| Card                             | File                      |
| -------------------------------- | ------------------------- |
| Crowdfunding Platform            | `crowdfunding.png`        |
| DevFlow                          | `devflow.png`             |
| Crop Suitability Prediction      | `crop-suitability.png`    |
| NeighborConnect                  | `neighborconnect.png`     |

Any web format works (png/jpg/webp). Landscape-ish screenshots look best —
they're displayed `cover`-cropped behind the card content with a dark scrim
on top so text stays readable.
